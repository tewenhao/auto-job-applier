# Master-doc skeleton (copy, then fill)

Copy this structure. Keep the block labels **exactly** — `**FACTS:**`,
`**VOICE:**`, `**PRIVATE — …:**`, `**LINKS:**` — they are parsed literally by
the ingestion pipeline. Delete any block that has no real content for an entry.

```markdown
# master document on <name>

## motivations/goals

**<1. A named motivation, in the candidate's framing.>**

- <A concrete bullet in the candidate's own explanation of this motivation.>
- <Another, grounded in a real example, not a slogan.>

*VOICE — <label> (verbatim, from <source>; my own writing, something I'm proud
of — reusable as authentic voice):*

> <A verbatim passage the candidate wrote. Copy it exactly — this feeds the
> voice model directly. Do not paraphrase or tidy it.>

**PRIVATE — handle deliberately:**
- <How to use / not use this per audience. A constraint, never a fact.>

## experience

### <Role> — <Org>, <Location>. <StartDate> - <EndDate | Present>

*<Optional one-line italic context that frames the whole entry.>*

**FACTS:**
- **The problem / context**: <what was true; honest scale anchors, not invented metrics>.
- **My role**: <precise contribution — what was yours vs the team's>.
- **Stack / how it works**: <tools, architecture, in bold where load-bearing>.
- **Status**: <honest status — shipped / demoed, adoption unclear / in development / pre-trial>.

**VOICE:**
- <Why it mattered / what it taught them, in the candidate's own reflective voice.>
- <A recurring thread they name themselves, or an honest caveat.>

**PRIVATE — do not surface externally:**
- <What not to claim; a number to avoid; a status not to overstate.>

**LINKS:**
- <Repo / paper (DOI) / marketplace / primary source. Note ownership if a teammate's.>

## education

### <Degree> — <Institution> (<College>)

**FACTS:**
- <Programme, funding, honest rank framing, notable modules.>

**Activities:**
- <Teams, competitions, societies — one line each.>

**VOICE:**
- <What the choice expresses about them, in their voice.>

**PRIVATE — handle deliberately:**
- <Any self-critical reaction to keep private; positive framing to use instead.>

## current/previous projects

### <Project name>. <Date>

**FACTS:**
- <What it is, stack, how it was built, honest split of hand-written vs AI-assisted.>

**VOICE:**
- <What it shows about how they think, not just that they can build.>

**LINKS:**
- <Repo.>

## achievements/awards

### <Award / placement> — <Event / body>

**FACTS:**
- <What was built, the result, the role.>

**VOICE:**
- <The honest story behind the result.>

**PRIVATE — do not surface externally:**
- <No external validation to imply; repo ownership; unverified figures.>

**LINKS:**
- <Primary source for the award; team repo with role noted.>

## volunteering

### <Programme> — <Org>. <Date>

**FACTS:**
- <Role, scope, honest scale.>

**VOICE:**
- <Why it matters to them.>

**PRIVATE — note:**
- <Don't overstate scale / don't imply a tech angle if there isn't one.>

## hobbies (that make me human)

### <Hobby> (<duration>)

**FACTS:**
- <Level, competitions, roles.>

**VOICE:**
- <Why they do it; what it says about them — persistence, balance, creativity.>
```
